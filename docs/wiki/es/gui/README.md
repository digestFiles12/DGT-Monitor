# Índice de la interfaz gráfica
Índice de las páginas de referencia del adaptador de escritorio PyQt6.
## Dependencias
Estas páginas documentan el adaptador de escritorio PyQt6 y sus dependencias internas de la aplicación.
## Contenido
| Página | Descripción |
|---|---|
| [__main__.py](__main__.md) | Arranque como módulo. |
| [entrypoints.py](entrypoints.md) | Configura y ejecuta la aplicación Qt. |
| [main_window.py](main_window.md) | Ventana principal, filtros y tabla de incidencias. |
| [theme.py](theme.md) | Normalización de tema y estilos Qt. |
| [workers.py](workers.md) | Cargas en segundo plano de incidencias, cámaras e imágenes. |
| [dialogs_cameras.md](dialogs_cameras.md) | Diálogo de cámaras cercanas y visor de imagen. |

### Alcance
La GUI PyQt6 es opcional para el proyecto final y se ejecuta localmente; no es la interfaz web desplegada.
