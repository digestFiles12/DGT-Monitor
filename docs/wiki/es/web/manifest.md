# dgt_monitor/web/static/manifest.webmanifest
Proporciona los metadatos de instalación de la aplicación web progresiva DGT Monitor.
## Dependencias
Formato JSON de Web App Manifest; el navegador lo consume mediante el enlace `rel="manifest"` de `index.html`.
## Contenido
### Campos PWA
- `name` y `short_name` son “DGT Monitor”; `description` describe el monitor de incidencias/cámaras. `start_url: "/"` fija el inicio, `display: "standalone"` solicita presentación independiente, y `background_color` es `#f5f6f4` y `theme_color` es `#b91c1c`. `lang: "es"` declara el idioma.
