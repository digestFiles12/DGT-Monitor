# dgt_monitor/web/static/manifest.webmanifest
**ES:** Proporciona los metadatos de instalación de la aplicación web progresiva DGT Monitor.
**EN:** Provides installation metadata for the DGT Monitor progressive web app.
## Dependencies / Dependencias
Formato JSON de Web App Manifest; el navegador lo consume mediante el enlace `rel="manifest"` de `index.html`.
Web App Manifest JSON format; the browser reads it through the `rel="manifest"` link in `index.html`.
## Contents / Contenido
### PWA fields
- **ES:** `name` y `short_name` son “DGT Monitor”; `description` describe el monitor de incidencias/cámaras. `start_url: "/"` fija el inicio, `display: "standalone"` solicita presentación independiente, y `background_color` es `#f5f6f4` y `theme_color` es `#b91c1c`. `lang: "es"` declara el idioma.
- **EN:** `name` and `short_name` are “DGT Monitor”; `description` describes the incident/camera monitor. `start_url: "/"` sets the launch URL, `display: "standalone"` requests a standalone presentation, and `background_color` is `#f5f6f4` and `theme_color` is `#b91c1c`. `lang: "es"` declares the language.
